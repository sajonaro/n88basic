Two paths, and only one of them runs anything

The squiggles come from the interpreter's own front end compiled to JavaScript and living inside the editor — it reads your program but never executes it. Running is a separate path that starts a real n88 process. A red underline is not a failed run, and a clean file is not a program that works.
